# palette · 2026

the artwork and the hypeddit gates moved to this palette in 2026: a cooler bone, a brighter crimson, a paler gold. the site follows so the three read as one object. every variable name is unchanged; only the values moved.

| variable | old | new | note |
|---|---|---|---|
| `--ink` | `#0a0908` | `#050403` | deeper, still warm |
| `--ink-2` | `#141210` | `#0f0d0b` | lifted warm black for sheets |
| `--ink-3` | `#1c1916` | `#181512` | hover surfaces |
| `--bone` | `#f1ece1` | `#f7f8f9` | cooler off-white, never `#fff` |
| `--bone-2` | `#d9d2c4` | `#d9d8d4` | dimmed foreground |
| `--bone-3` | `#8a8478` | `#8b8a86` | metadata |
| `--bone-4` | `#4a4641` | `#4a4845` | hairlines, faint labels |
| `--ember` | `#c93829` | `#cd2d44` | bright crimson · the one mark per screen |
| `--ember-deep` | `#8a2317` | `#6c1723` | pressed ember |
| `--ash-gold` | `#b78f54` | `#d8b875` | secondary accent, rarer than ember |
| `--ash-gold-2` | `#836138` | `#975434` | deep gold |
| `--peach` | — | `#eeb59a` | new · reserved, rarely used |

hairlines, scrims and grain derive from `--bone` and `--ink`, so they moved with them: `rgba(247, 248, 249, …)` and `rgba(5, 4, 3, …)`.

fonts stay cormorant garamond · jetbrains mono · manrope.
